# 局部麻醉药：面向兽医麻醉师的全面综述

> **摘要**：全面综述局部麻醉药的生理学基础、化学结构与分类、药理特性、临床应用与剂量，以及局部麻醉药全身毒性（LAST）的识别、预防与处理。

局部麻醉药：面向兽医麻醉师的全面综述 — 涵盖生理学、化学、分类、药理特性及全身毒性（LAST）。给兽医麻醉师的一份全面综述 — 覆盖生理学、生化、分类。议程 01 生理学：神经纤维类型、离子通道与神经传导机制 02 药理学：分子结构、pKa、脂溶性与蛋白结合 03 分类：氨基酯类与氨基酰胺类 — 代谢与致敏潜力 04 特性与剂量：辅助药、药物联合与临床应用 05 并发症与安全性：局部麻醉药全身毒性 — 识别与治疗 局部麻醉 局部麻醉的概念是在特定区域选择性阻断神经传导。在兽医学中，该技术应用于小动物、大动物及食用动物，使患者在清醒或轻度镇静状态下完成操作，减少对全身麻醉及其相关风险的需求，并改善疼痛控制与动物福利。在全身用药选择受限的情况下尤其有价值。回归基础：生理学 电压门控钠通道（Na⁺）是局部麻醉药的主要靶点。理解其三种功能状态 — 静息（关闭）、开放，以及失活（关闭）— 对理解局部麻醉药的作用机制至关重要。静息
（关闭）通道处于 −70 mV。电压感受器（S）处于关闭构象。无 Na⁺ 电导。开放 去极化触发开放，Na⁺ 内流，动作电位传播。失活
（关闭）1–2 ms 后，失活门（I）关闭，通道处于不应期。复极化恢复静息状态。3 种状态 — 1 个结合位点 局部麻醉药结合于 α 亚基 DIV S6 段的通道孔内。这是介导通道阻滞的关键结合位点。作用机制 主要靶点：电压门控 Na⁺ 通道 局部麻醉药主要作为电压门控钠通道的离子通道阻滞剂，阻止动作电位产生与传播所需的快速 Na⁺ 内流。次要靶点：K⁺ 与 Ca²⁺ 通道 局部麻醉药也阻断电压门控钾通道与钙通道，但亲和力较低。在高血浆浓度下，这些效应参与全身毒性。细胞内信号转导 已有描述认为其可能对参与 G 蛋白偶联受体信号转导的细胞内位点产生额外作用。弱碱 — 离子化形式结合受体 局部麻醉药为弱碱。只有离子化（带电荷）形式与受体结合。这对起效时间具有关键意义，尤其在炎症组织中。

作用机制 — 膜通路 局部麻醉药的离子化（BH⁺）与非离子化（B）形式均具有临床意义。脂溶性的非离子化形式直接穿过细胞膜，而带电荷形式则经开放的通道孔进入。进入后重新离子化，并与 DIV S6 段的受体（R）结合，阻断 Na⁺ 电导。作用机制 — 调节受体假说 \"局部麻醉药对处于开放和失活状态的 Na⁺ 通道具有更高的结合亲和力。\" 状态依赖性结合 局麻药分子优先与开放及失活构象的通道结合。脂溶性形式直接经膜抵达；脂溶性较低的带电荷形式仅能经通道孔进入。

活动中的累积性结合 反复去极化使处于开放/失活状态的通道比例增加，导致药物累积性结合，连续刺激下阻滞逐渐加深。临床意义 这解释了为何阻滞深度随反复去极化而增加 — 这是使用依赖性（相位性）阻滞的基础，已被用于疼痛管理与心律失常治疗。作用机制：门控受体假说 \"门控\"概念 局麻药受体位于通道内部。通道门在物理上\"守卫\"着受体的进入路径。通道必须开放，局麻药分子才能到达结合位点。刺激频率增加 → 更多通道处于开放/失活状态 → 局麻药结合增加 → 阻滞加深。

两种阻滞类型 • 张力性（静息性）阻滞：在未受刺激的神经上观察到的持续性阻滞，由药物与静息状态通道结合所致。• 相位性（使用依赖性）阻滞：随反复膜去极化而逐渐加深的阻滞。临床用于疼痛控制与抗心律失常效应。两种假说都试图解释为何阻滞深度随反复膜去极化而增加 — 这一现象称为\"使用依赖性\"或\"相位性\"阻滞。差异性神经阻滞 局部麻醉药并非同等阻断所有神经纤维。存在特征性的阻滞顺序，从血管扩张到感觉丧失，最后是运动丧失。

这种差异性阻滞不仅取决于纤维直径，还取决于纤维类型、刺激频率、神经暴露于局麻药的长度，以及所用药物与浓度。血管扩张 最先观察到的效应 — 交感缩血管张力丧失 温度与锐痛 随后丧失温度觉与伤害性感觉 触觉与压觉 轻触觉与压觉接着被阻断 运动活动 运动功能丧失最后出现（需要最高浓度）较小纤维仅需暴露 3 个郎飞结即可完全阻滞，而较大纤维需要更长段的暴露神经 — 部分解释了差异性阻滞。差异性阻滞 — 神经纤维分类 神经纤维按直径、髓鞘化与传导速度分类。

局麻药的阻滞顺序遵循可预测的模式：C 纤维（疼痛、温度、自主神经）首先被阻滞，其次是 Aδ 纤维，然后是 Aβ 纤维，最后是大直径 Aα 纤维（运动、本体感觉）。注意，仅凭纤维大小并不能完全解释差异性阻滞 — 纤维类型与使用依赖性同样起重要作用。

1 亲脂性芳香环 取代苯环，负责膜穿透与效能 2 中间链 酯键或酰胺键（6–9 埃）— 决定药物类别与代谢途径 3 亲水性胺基 叔胺或季胺 — 决定离子化状态、pKa 与受体结合 分类：酯类与酰胺类 氨基酯类 示例：普鲁卡因（Procaine）、丁卡因（Tetracaine）、苯佐卡因（Benzocaine）代谢：由血浆假性胆碱酯酶水解，在血流中迅速分解。过敏风险：水解产生对氨基苯甲酸（PABA）— 一种潜在致敏代谢物。酯类真正过敏反应较酰胺类更常见。

氨基酰胺类 示例：利多卡因（Lidocaine）、甲哌卡因（Mepivacaine）、布比卡因（Bupivacaine）、罗哌卡因（Ropivacaine）、左布比卡因（Levobupivacaine）代谢：经 CYP450 酶在肝脏代谢，分解较慢；肝疾病时可能蓄积。过敏风险：过敏反应罕见。真正的酰胺类过敏极为少见；反应常归因于防腐剂或血管收缩剂。记忆口诀：酰胺类局麻药通用名中含两个字母\"i\"（lidocaine、mepivacaine、bupivacaine）。

理化性质 — 临床意义 分子量 分子量越大（体积越大）→ 向作用部位扩散减少 → 起效越慢，但清除也越慢 → 持续时间延长。扩散受限使全身副作用减少。pKa → 起效时间 pKa 越高 → 在生理 pH（7.4）下离子化程度越高 → 起效越慢。只有非离子化（碱基）形式能跨膜。在 pH 7.4 时，pKa 越接近 7.4 的药物，非离子化比例越高。脂溶性 → 效能 亲脂性越高 → 穿过神经鞘膜的扩散越好 → 给药剂量中到达神经元的比例越高。与麻醉效能直接相关，同时减少全身吸收。

蛋白结合 → 持续时间 只有游离（未结合）部分具有药理活性。蛋白结合率越高 → 作用持续时间越长。高亲脂性与高蛋白结合可减少全身吸收，降低毒性风险。

混合局部麻醉药？不可预测的结果 混合局部麻醉药会导致可变且不可预测的临床结果。最终阻滞取决于多种因素，包括混合液的最终 pH。短效 + 长效药物联用 将利多卡因或甲哌卡因与布比卡因或罗哌卡因混合，可缩短起效时间，但持续时间也比单用长效药物更短 — 往往与预期目标相反。毒性叠加 联合使用局麻药的全身毒性具有叠加性。务必计算所有药物的总剂量，同时在多个部位进行阻滞时尤其重要。一般而言，不建议混合市售局麻药溶液。应根据所需阻滞持续时间与起效时间选择单一合适药物。局部麻醉药的辅助药 血管收缩剂 肾上腺素、去氧肾上腺素/甲氧明可减少全身吸收 → 降低所需剂量、延长持续时间。风险：在终末动脉区域（指/趾、耳）使用可致组织坏死，且严禁静脉注射（2.5–5 μg/ml）

透明质酸酶 通过分解透明质酸改善组织通透性，缩短起效时间并扩大阻滞范围。适用于致密组织中的浸润阻滞。（每 10 ml 1 mEq — 与布比卡因和罗哌卡因产生沉淀）α₂-肾上腺素能受体激动剂 右美托咪定及类似药物通过使 C 纤维超极化延长镇痛持续时间，是外周神经阻滞与硬膜外镇痛的协同辅助药。（每 ml 局麻药溶液 1 μg）阿片类药物 例如无防腐剂吗啡常用于硬膜外/蛛网膜下腔给药，使镇痛持续长达 24 h（副作用为尿潴留与瘙痒）临床应用与药物概览 兽医临床最相关的局麻药包括：利多卡因（用途最广，可静脉使用）、甲哌卡因（关节内给药首选）、布比卡因与罗哌卡因（长效，用于神经阻滞、硬膜外），以及左布比卡因（心脏安全性改善）。注意 快速耐受性：反复给予同一局麻药可能导致阻滞效能进行性下降。这与硬膜外导管技术及重复给药最为相关。临床相关局麻药市售制剂、适应证与剂量 局麻药 市售制剂 适应证 剂量 起效时间 麻醉 镇痛 普鲁卡因 奴佛卡因（Novocaine）、Procasel、Adrenacaine、Dalcain、Irocain（含肾上腺素）• 浸润• 神经阻滞 最大剂量：

逆转局部麻醉？甲磺酸酚妥拉明（OraVerse®）— 一种 α 肾上腺素受体拮抗剂 — 可注射于含肾上腺素的局麻药阻滞部位，加速软组织麻木的逆转。它逆转肾上腺素诱导的血管收缩，增加局部血流，加快药物清除。目前主要用于人牙科，兽医应用仍在研究中。

其他不良反应 神经毒性 直接神经损伤罕见但可能发生。所有局麻药均有潜在神经毒性；毒性与麻醉效能相关。周围神经较脊髓与神经根不易受累。肌毒性 局麻药可引起骨骼肌损伤，尤其在重复或大剂量注射时。通过合理选药与剂量管理通常可逆。软骨毒性 局麻药具有软骨毒性，尤其在长时间暴露与较高浓度时。布比卡因与利多卡因最常涉及。甲哌卡因软骨毒性似乎较低，为关节内给药首选。高铁血红蛋白血症 某些局麻药
（尤其是丙胺卡因 Prilocaine、苯佐卡因 Benzocaine）可诱导高铁血红蛋白形成，降低携氧能力。在猫及高铁血红蛋白还原酶活性有限的物种中具有临床意义。经口毒性与过敏反应 某些局麻药制剂被动物摄入后有毒。真正的过敏反应（酯类经 PABA 最常见）罕见，但必须与迷走神经性晕厥反应或 LAST 相鉴别。LAST — 预防 LAST 的预防 注射前安全方案：RAPT 核查表

（NYSORA）• 反应（运动）：注射时观察不自主运动或抽动。神经内或血管内注射的早期体征可在给药期间出现，在镇静状态下可能被误认为正常反应。• 回抽：每次注射前均需回抽以检测可能的血管穿刺。在 90° 与 45° 角度多次回抽比单次回抽更可靠。• 压力（低）：以最小阻力缓慢注射。高压力可能提示针尖位于神经束内或血管内。理想情况下使用注射压力监测装置。• 局麻药总量：准确计算并记录累积剂量，尤其在多部位阻滞或术中追加给药时。

超声引导的使用• 直接可视化神经、周围结构与血管解剖。• 实现精准穿刺，降低血管穿刺或注入高血管分布组织的风险。• 可确认局麻药扩散，以更低容量确保有效神经阻滞。在条件允许时，当超声图像质量不佳，可联合神经刺激以增强确认。分次注射技术• 将局麻药总剂量分为小份（0.5–1 mL）。• 每次注射后：短暂停顿，观察有无运动或心血管变化。继续给药前再次回抽。• 该方法可最大限度降低大容量血管内团注的风险，而后者是 LAST 最危险的诱因。

个体化给药策略• 始终使用达到阻滞所需的最低有效浓度与容量。• 按 mg/kg 计算最大剂量，但对幼年与老年患者、合并疾病动物（如心力衰竭、肝病）应格外保守。• 大范围阻滞（如 TAP 阻滞）优先选择短效药物或稀释制剂。其他预防措施

• 监测：操作期间及术后数小时内始终保持监测。• 备好脂肪乳：开展区域阻滞的诊所应储备 20% 脂肪乳并制定应急预案。• 记录与沟通：记录确切剂量、部位与技术；向恢复团队简要说明潜在迟发毒性体征。不良反应 神经毒性与神经损伤 直接神经损伤虽罕见，却是局麻药给药的严重并发症，与全身毒性不同。病因与机制• 机械性创伤：穿刺或注射时针头直接损伤神经纤维。• 化学毒性：高浓度或长时间暴露于局麻药可直接损伤轴突与髓鞘。

• 缺血：血管收缩剂（如肾上腺素）或大容量注射液的压迫可损害神经血供。• 炎症/水肿：组织对注射液的反应，导致肿胀与神经压迫。• 神经内注射：直接注入神经束，造成即刻机械与化学损伤。风险增加因素• 局麻药浓度与容量：浓度越高、容量越大，毒性潜力越大。• 神经类型：脊髓与神经根较周围神经更敏感。• 患者合并症：糖尿病、血管疾病或既往神经病变可增加易感性。• 操作技术：多次穿刺、高注射压力或回抽失败。

临床表现与预后• 症状可从暂时性感觉异常到永久性感觉丧失、运动无力或神经病理性疼痛。• 起效可即刻或延迟。• 大多数神经损伤为一过性，但严重病例可导致持久残疾。• 早期识别与处理对获得良好结局至关重要。始终将神经毒性与 LAST（局部麻醉药全身毒性）相鉴别。两者虽均涉及局麻药，但其机制与初始治疗不同。
