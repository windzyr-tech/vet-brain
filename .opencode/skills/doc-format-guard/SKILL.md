# 文档格式规范与校验

这个 skill 只关心一件事：**每篇打开的知识文档都有稳定、一致、专业的阅读格式**。它不负责扫描、翻译或建站。

## 何时使用

- 用户说「文档格式不稳定」「标题/字体/颜色不一致」「每篇文章应该有摘要和目录」
- 扫描或翻译完成后，需要统一所有文档的呈现结构
- 新增一种文档来源后，需要确认产出格式是否一致

## 目标结构

每篇文档必须包含：

1. **标题**：frontmatter `title` + 正文唯一一个 H1，两者一致
2. **摘要**：frontmatter `description`，并在标题下方显示 `> **摘要**：...`
3. **具体内容**：正文主体，标题层级清晰
4. **目录**：篇幅较长（≥1200 字且有 3 个以上二级标题）的文档，在摘要后插入 `## 目录`
5. **干净的样式**：没有内联 `style`、`font` 标签等导致字体大小/颜色不一致的残留

详细的字段与示例见 `references/structure.md`。

## 工作流程

1. 先检查：`pnpm run format:check`，查看哪些文档不符合规范。
2. 自动修复：`pnpm run format:fix`。
3. 人工复核：
   - 标题是否准确，是否与 frontmatter 一致
   - 摘要是否真的概括了文档，而不是截取了第一句话
   - 目录层级是否合理，长文是否确实需要目录
   - 专业术语、拉丁学名、剂量单位是否被误改
4. 修复后运行 `pnpm run build`，确认检索与图谱不受影响。

## 边界

- 不改动文档的专业内容与事实表述，只调整结构和呈现。
- 不改动 `contentHash`、`syncedFrom`、`sourceName` 等来源字段。
- 英文文档的翻译属于 `vet-translation` skill；本 skill 只保证格式，不负责翻译。
- 扫描与生成属于 `vetbrain-knowledge-site` skill。
