# 专业内容分段

这个 skill 只解决一件事：**让内容按知识逻辑分段，读者能顺畅阅读，而不是面对一整块文字墙**。它不负责翻译、格式校验或建站。

## 何时使用

- 用户说「内容都堆在一起」「段落不合理」「读起来很累」
- 文档里出现几百甚至上千字没有换行的整段文字
- PDF / PPTX 抽取后，编号条目被挤在同一行
- 需要按主题把长内容拆成带小标题的章节

## 分段原则

1. **以知识内容为轴**：每段只讲一个意思；主题变化时另起段落或小节。
2. **标题必须概括内容**：小标题写「局部麻醉药的分类与代表药物」，不写「幻灯片 3」「第一部分」「内容」。
3. **段落长度适中**：中文正文一般 150～300 字一段；超过 500 字必须拆分。
4. **保留专业结构**：解剖、药理、操作要点、剂量、禁忌证等按专业逻辑分节。
5. **不破坏原文事实**：只调整分段与标题，不改专业结论、剂量、药名、缩写与拉丁名词。

## 工作流程

1. 先检查：`pnpm run segment:check`，列出存在超长段落的文档。
2. 基础拆分：`pnpm run segment:fix`，在句子边界拆段、把挤压编号拆成列表。
3. 语义重组（人工/我来做）：对仍然过长的章节，按主题补充内容型 H2/H3 小标题，让目录真正反映知识结构。
4. 再运行 `pnpm run format:check`，必要时 `pnpm run format:fix -- --toc` 重建目录。
5. 最后运行 `pnpm run build`，确认检索与图谱正常。

## 与其他 skill 的关系

- `vetbrain-knowledge-site`：负责扫描与生成文档
- `vet-translation`：负责把英文译成专业中文
- `doc-format-guard`：负责标题、摘要、目录、样式等格式规范
- 本 skill：负责段落与章节的知识逻辑结构
