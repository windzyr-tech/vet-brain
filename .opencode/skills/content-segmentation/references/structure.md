# 专业分段标准

## 什么算「堆在一起」

- 单个自然段超过 500 字，没有换行
- 多个主题挤在同一个段落里
- 编号条目被抽取成一行：`1. 适应证 ... 2. 禁忌证 ... 3. 剂量 ...`
- 小标题是「幻灯片 1」「第一节」「内容」这类格式标签，而不是知识点

## 目标结构

```markdown
# 局部麻醉药：药理、剂量与安全性

> **摘要**：...

## 局部麻醉药的分类

按化学结构分为酯类与酰胺类，代表药物与代谢途径如下……

## 作用机制与药代动力学

...

## 临床剂量与给药途径

...

## 毒性反应与并发症管理

...
```

## 段落规则

- 一段只讲一个核心意思。
- 中文正文每段 150～300 字；超过 500 字必须拆分。
- 句子边界优先在句号、问号、叹号、分号后。
- 列表、表格、引用、代码块保持原样，不强行并入段落。
- 编号条目拆成独立列表项，便于阅读与检索。

## 标题规则

- 用知识点命名，例如「超声引导下神经阻滞的适应证」「膈肌的解剖与功能」。
- 不使用「幻灯片 N」「段落 1」「第几部分」等来源或格式标签。
- 同一文档内标题不重复；相近主题用限定词区分。

## 自动脚本的边界

`segment:fix` 只做机械拆分：在句子边界切段、把挤压编号拆成列表。它不会判断主题，也不会生成内容型小标题。语义层面的重组必须由我读完内容后完成。

因此流程是：**先脚本拆分 → 再人工按知识逻辑加小标题 → 重建目录 → 构建**。
