# 相关内容推荐

这个 skill 只负责一件事：**让每篇文档底部都有至少 5 个真正相关、可点击的延伸阅读入口**。

## 何时使用

- 用户说「文档底部加相关内容」「推荐相关文档」「至少 5 个相关链接」
- 知识库建成后，需要把孤立文档连成可浏览的知识网络
- 目录分类不足以表达文档之间的实际关联

## 相关性依据

不是按目录或标题硬凑，而是综合：

1. frontmatter 的 `tags`、`concepts`、`category`
2. 正文中的中文词组与专业术语
3. `data/concepts.json` 与 `data/glossary.json` 命中的概念

使用倒排文档频率加权：越少见、越能代表主题的术语，权重越高。若内容相似度不足 5 篇，先按同分类补齐，再从全库补齐，保证每篇至少 5 个链接。

## 工作流程

1. 预览：`pnpm run related:check`，查看每篇将推荐的 slug。
2. 写入：`pnpm run related:fix`，在文末生成或替换 `## 相关内容` 区块。
3. 校验：`pnpm run format:check`，必要时 `pnpm run format:fix -- --toc` 更新目录。
4. 构建：`pnpm run build`，确认链接指向的文档页面都已生成。

## 输出格式

```markdown
## 相关内容

- [颈总动脉与颈外动脉](/docs/17-头颈部血供-pdf/)
- [前肢血供](/docs/14-前肢血供-pdf/)
- ...
```

## 边界

- 链接必须指向站内已存在的文档，使用 `/docs/<slug>/`。
- 不修改正文知识内容，只在文末追加/替换相关内容区块。
- 不把当前文档自己列入推荐。
