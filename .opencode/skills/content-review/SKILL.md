# 内容专业审核

这个 skill 只负责一件事：**判断内容是不是专业兽医知识，并把无关紧要的内容清出去**。它不负责翻译、分段、格式或建站。

## 何时使用

- 用户说「审核内容」「过滤无关内容」「这些不是专业知识」
- 文档里混入网址、课程宣传、讲师姓名、日期、版权、页码等噪声
- 需要确认一批资料是否适合纳入专业兽医知识库

## 审核标准

### 应保留

- 解剖、生理、病理、药理、麻醉、临床诊断与治疗等专业知识
- 剂量、适应证、禁忌证、并发症、操作步骤、超声标志、神经阻滞入路
- 专业术语、拉丁学名、药名、缩写、检查指标
- 与动物医学直接相关的临床要点与机制解释

### 应过滤

- 网址、邮箱、版权声明、页码
- 讲师姓名、课程日期、培训宣传语（如“3-Day Continuing Education Course”）
- 与专业知识无关的寒暄、目录说明、重复页眉页脚
- 无法判断专业含义、且与兽医/动物医学无关的段落（先标记，人工确认后再处理）

## 工作流程

1. 运行 `pnpm run review:check`，查看噪声块与「待人工确认」段落。
2. 对**明确的噪声**（网址、版权、页码、课程宣传等）运行 `pnpm run review:fix` 直接过滤。
3. 对「待人工确认」段落逐条判断：
   - 属于专业知识 → 保留
   - 无关紧要 → 删除
   - 不确定 → 保留并询问用户
4. 过滤后运行 `pnpm run format:check`、`pnpm run segment:check`，确认结构与分段仍正常。
5. 最后 `pnpm run build` 验证检索与图谱。

## 边界

- 不修改专业事实、剂量、术语与结论。
- 不因为是英文就过滤——英文专业知识由 `vet-translation` skill 翻译处理。
- 不删除标题、摘要、目录等结构元素。
