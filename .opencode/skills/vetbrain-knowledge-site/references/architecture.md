# 这个项目是做什么的

**让兽医知识形成可检索、可关联的知识网络。**

系统整合专业文献、临床资料与学术文档，按学科体系分类整理，提供精准检索与知识图谱导航。持续更新，随时呈现最新知识脉络。

项目把本机固定文件夹里的资料（PDF、Word、PPTX）持续整理成三类成果：

1. **可阅读的知识文档**：按来源目录自动分到「解剖」「神经学课件」「超声引导局部麻醉」等分类，每份资料一篇独立页面。
2. **可检索的知识库**：输入关键词就能找到相关段落，支持中文与专业术语。
3. **可浏览的知识图谱**：知识点之间按共同概念连成网络，能看到哪些资料彼此相关。

## 一次完整更新的过程

```
本机资料文件夹
  → 增量扫描：只处理新增 or 变化的文档
  → 英文文档标记待翻译：由 OpenCode 按兽医术语表译成专业中文
  → 生成知识文档，放入 content/synced/（会被 Git 跟踪）
  → 生成知识图谱数据与检索索引
  → 提交并推送
  → 下次打开网站，看到的就是最新内容
```

## 目录速查

| 位置 | 项目里的角色 |
| --- | --- |
| `vetbrain.config.json` | 项目总设置：扫哪些文件夹、什么时候扫、是否推送 |
| `content/synced/` | 扫描与翻译后的正式知识文档 |
| `content/raw/`、`content/manual/` | 手动补充的原始资料与手写笔记 |
| `data/concepts.json` | 知识图谱使用的概念表 |
| `data/glossary.json` | 英译中时统一使用的兽医术语表 |
| `.cache/scan-state.json` | 扫描进度记录，不影响网站内容 |

## 为什么要这样安排

- 本机文件夹只有你能访问，所以**扫描**在你的电脑上按设定时间执行。
- 网站发布在 Cloudflare Pages，收到推送后自动重建，**检索索引和图谱也随推送一起更新**。
- 翻译由 OpenCode 完成，是为了保证兽医专业术语准确、风格统一，而不是交给通用机器翻译。
